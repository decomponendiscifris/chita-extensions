# Changelog

## 0.4.0

Flow: feature, release and hotfix branches by the repository's gitflow conventions, started, finished (merged, tagged, deleted) and published from a screen of their own, with a commit message convention (imperative, or Conventional Commits) that Commit… checks. Rebase a branch onto another, force push with lease, push a branch with no upstream yet, the history of one file. Clone a repository here from an address you type into Chita's own prompt, or make one. Submodules listed with the worktrees and in the column. Templates to insert in the .gitignore editor. The Git column marks each state with a symbol and dims ignored items.

## 0.3.0

A repository is a place: a header with the branch, what changed and what's in progress, with Fetch, Pull, Push and Commit; Changes with conflicts, staged, changed, untracked and stashes, Discard that keeps a copy for a week and Undo Discard, Amend and Stash All; Branches with checkout, merge and delete, and tags; History with the commit graph, branches and tags from a commit, cherry-pick and revert; Worktrees; the diff of what you select in the Inspector; .gitignore from the menu and an editor; the name and email asked once when the repository has none. Asks to write in the folder you're viewing, for .gitignore.

## 0.1.1

For the store: a category, a line on each command, and an icon. Nothing changes in what it does.

## 0.1.0

The first release: the Git column, the Git panel, and Stage, Unstage, Commit…, Show
Changes, Show History, Fetch, Pull and Push.
