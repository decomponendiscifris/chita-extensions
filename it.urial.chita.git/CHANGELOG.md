# Changelog

## 0.3.0

A repository is a place: a header with the branch, what changed and what's in progress, with Fetch, Pull, Push and Commit; Changes with conflicts, staged, changed, untracked and stashes, Discard that keeps a copy for a week and Undo Discard, Amend and Stash All; Branches with checkout, merge and delete, and tags; History with the commit graph, branches and tags from a commit, cherry-pick and revert; Worktrees; the diff of what you select in the Inspector; .gitignore from the menu and an editor; the name and email asked once when the repository has none. Asks to write in the folder you're viewing, for .gitignore.
